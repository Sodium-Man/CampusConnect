# 🎓 CampusConnect – Event Organising System

**KIT502 Assignment – University of Tasmania**

CampusConnect is a web-based event organising platform designed to simplify how users create, manage, and explore campus events. The system provides an intuitive and user-friendly interface for event planners, attendees, and administrators.

---

## 📌 Project Overview

CampusConnect enables users to:

- 📅 Create and manage events  
- 🔍 Explore available campus events  
- 👥 Register and participate in events  
- 🛠️ Administer and monitor platform activity  

The platform focuses on **front-end development, UI/UX design, and database planning**, while preparing for future full-stack implementation.
